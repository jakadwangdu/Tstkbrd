# Aura Keyboard OS

A warm-minimalist keyboard app, packaged for Android and iOS with Capacitor, plus a small Node.js API and an Android keyboard source file.

## What is in here
- `www/index.html` : the app. The same file runs in a browser and inside the Android and iOS shells (in the shells it goes full screen).
- `capacitor.config.json`, `package.json` : the app shell settings (app id `app.aura.keyboard`).
- `.github/workflows/build-apps.yml` : builds a debug APK and an unsigned debug IPA, then publishes both to GitHub Releases.
- `server/` : Express API, OpenAPI spec and `package.json`.
- `native-ime/AuraKeyboardIME.kt` : Kotlin `InputMethodService` for a system-wide Android keyboard. Not part of the app build and not compiled or tested.

The `android/` and `ios/` projects are generated by the workflow, so they are not stored in the repo.

## How the builds work
Every push to `main` (and every manual run) starts the workflow:
1. **Android job** generates the Android project, runs `./gradlew assembleDebug`, and uploads `app-debug-apk`.
2. **iOS job** (macOS runner) generates the iOS project, builds without code signing, packs `Payload/App.app` into an `.ipa`, and uploads `ios-debug-ipa`.
3. **Release job** publishes a GitHub Release tagged `debug-build-RUN-ATTEMPT` with the APK and IPA attached. If the iOS job fails, the APK is still released.

Find the files under **Releases > Assets**, or under the run's **Artifacts**.

## Installing
- **Android:** open the `.apk` from the release on your phone and allow installs from your browser or file manager.
- **iOS:** the IPA is unsigned, so iPhones will not install it directly. Re-sign and install it with AltStore or Sideloadly using your Apple ID. A signed build for TestFlight or the App Store needs a paid Apple Developer account, which the workflow does not use.

## Limits
- Inside the app, the keyboard types into its own note editor. It is not yet a system keyboard for other apps.
- A system-wide Android keyboard needs `native-ime/AuraKeyboardIME.kt` added to a native project. A system-wide iOS keyboard needs a Swift keyboard extension, which is not included.
- The workflow has not been run yet. First runs often need small fixes, such as an Xcode or Gradle version change. Read the failing step's log and send it to me.

## Run the API
    cd server
    npm install
    npm start        # http://localhost:8787/v1/health
